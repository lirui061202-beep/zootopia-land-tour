# 疯狂动物城园区 · 虚拟游览

上海迪士尼乐园「疯狂动物城」主题园区的可步行三维模型，可以在白天、黄昏、夜晚之间切换，夜里能看到远处城堡方向的烟花。纯网页，用浏览器打开就能逛。

这是爱好者做的非官方还原，仅供个人游览参考，不作商业用途。Zootopia / 疯狂动物城及相关名称归 Disney 所有；模型里不包含官方角色形象和商标图形，招牌上的动物是原创的替代形象。

## 怎么打开

**在线**：<https://lirui061202-beep.github.io/zootopia-land-tour/>（首次加载约 40 MB，请耐心等进度条走完）。

**本地**：

1. 下载或克隆本仓库。
2. 装有 [Node.js](https://nodejs.org/) 的话，Windows 双击 `start.bat`；其他系统在项目目录运行 `node serve.mjs`，然后打开 <http://localhost:5183/>。
3. 没有 Node.js 也行：项目是纯静态网页，任何静态服务器都可以，例如 `python -m http.server 5183`。直接双击 `index.html` 不行，浏览器不允许本地文件加载模块。

请用电脑上的 Chrome 或 Edge。目前没有触屏操作，手机上不能走动。

## 卡的话

- 进园前页面会自动测速并调整渲染分辨率，开始画面上会显示测得的每帧毫秒数。
- 笔记本有独立显卡时，在 Windows「设置 › 系统 › 屏幕 › 显示卡」里把浏览器设为「高性能」再重开，画质和帧率都会好很多。
- 地址后面加 `?fast` 可以关掉环境光遮蔽和体积光；加 `?high` 强制高画质。

## 还原到什么程度

- **平面布局**：建筑轮廓和道路取自 OpenStreetMap，再对着卫星图逐栋校正；座椅、食集摊位、遮阳伞的位置取自实地漫游视频。小物件的位置误差约 2～3 米。
- **立面和招牌**：立面是按实景照片的描述生成的图，再按深度图做成浮雕；招牌文字只用了照片里能看清的。
- **远景**：正南约 313 米处的城堡背影和烟花。城堡与园区之间实际还有矿山车的山体，这里只放了树。
- **没做的**：室内、游乐设施内部、游客和演职人员。路灯和行道树是沿路按间距摆的，没有逐个考证。

## 目录

| 路径 | 内容 |
|---|---|
| `index.html`、`src/` | 页面和全部源码（three.js，无构建步骤） |
| `assets/tex/` | 运行时贴图（WebP）和清单 `manifest.json` |
| `assets/prompts/` | 生成立面图时用的提示词 |
| `tools/` | 生成、高清化贴图的脚本，以及对着卫星图核对布局的测量页 `survey.html` |
| `vendor/three/` | three.js r170（MIT 许可） |

贴图的 PNG 原图和高清化的中间文件体积很大（约 500 MB），没有放进仓库。改了 `assets/tex/` 里的文件后运行 `node tools/manifest.mjs` 更新清单。
